# Metric Definitions

## DATA-030：按估值日折现的三档情景价值（CR-029）

独立月度研究快照，币种USD；现金流/资产/负债参数用百万美元，股数用百万股，相除得到美元每股。计算唯一位置 `indicators.py:calculate_scenario_value`；前端仅展示数值并比较现价高低。参数与假设由逐只研究提供，无统一默认值。

`enterprise_dcf`：未来N个估值日起完整年度的FCFF为F_t，年WACC为r，长期增长g，现金及非经营资产C，债务及其他优先权益D，预计融资后稀释股数S。

```text
TV = F_N × (1+g) / (r−g)
EV = Σ[t=1..N] F_t / (1+r)^t + TV / (1+r)^N
每股价值 = max(EV + C − D, 0) / S
```

N为1–10，三个DCF情景的N一致；FCFF是扣除资本开支与营运资金投入的企业自由现金流，可含前期负值，但F_N必须为正；−1<g<r<=1，r>0，S>0，C/D>=0。r/g为小数而非百分数（0.10即10%）。没有持续经营正终值依据时不得机械套用DCF。FCFF中的资金消耗不能再重复扣减，融资路径须同时反映在经营投入预测和稀释股数中。

`asset_recovery`：可回收资产A，优先偿付债权D，回收/处置成本K，预计等待T年，年折现率r，现有普通股数S，现有普通股对剩余权益保留比例f（`existing_common_entitlement`）。

```text
现有普通股每股回收价值 = max(A − D − K, 0) × f / (1+r)^T / S
```

A/D/K>=0，S>0，0<r<=1，0<=T<=10，0<=f<=1。f必须有权益顺序/重组条款依据，不提供默认比例；普通股注销为f=0，即使企业残值为正，老股东回收仍为0。不能重复统计资产、现金和成本，不能用重组后新股权益替代现有股东回收。该值是假设成立时的回收价值，不是价格底线。

所有参数必须为有限数值，布尔值不作数值；不接受未知参数字段或未知模型。结果保留4位小数，要求乐观>=保守>=极端保守，异常不重排或修补，整份快照不覆盖。股权归零输出0，缺资料输出null并标pending，两者严格区别。该模型是本项目新研究工具，不改变原趋势指标及250/252窗口。

本文档是指标公式的权威技术说明。所有百分比字段保存百分比数值，例如 `5.25` 表示 `5.25%`；有效结果四舍五入到两位小数。

## 公共输入规则

- 数据按 `trade_date` 升序排序并按日期去重。
- `close`、`high`、`low` 必须是有效数值。
- `adjusted` 与 `raw` 从同一次批量下载中分别派生、分别计算，不共享历史基准。
- 至少两条日线才能生成一行。

## 当日涨跌 `today_return_pct`

```text
(最新 close / 上一条有效 close - 1) * 100
```

使用相邻有效数据点，不假设自然日前一天是交易日。该字段需要至少两条记录。

## 距 MA250 `distance_ma250_pct`

```text
MA250 = 最近 250 条有效 close 的算术平均
(最新 close / MA250 - 1) * 100
```

少于 250 条时返回 `null`。不得自动改用 MA200、MA240 或可用历史均值。

## YTD `ytd_return_pct`

```text
(最新 close / 当前自然年第一条有效 close - 1) * 100
```

如果当前年没有有效记录或基准为零，返回 `null`。加密资产也使用自然年第一条可用日线。

## 距 52 周高点 `distance_52w_high_pct`

```text
high_52w = 最近 252 条有效记录中的最大 high
(最新 close / high_52w - 1) * 100
```

少于 252 条时返回 `null`；通常不大于零。

## 距 52 周低点 `distance_52w_low_pct`

```text
low_52w = 最近 252 条有效记录中的最小 low
(最新 close / low_52w - 1) * 100
```

少于 252 条时返回 `null`；通常不小于零。

## 52 周区间位置 `position_52w_pct`

```text
(最新 close - low_52w) / (high_52w - low_52w) * 100
```

`0%` 对应区间低点，`100%` 对应区间高点。这是价格在线性区间中的位置，不是时间进度。少于 252 条或高低点相同时返回 `null`。

## 价格精度

`close` 在 JSON 中最多保留四位小数，以兼容低价股票和加密资产；页面中大于等于 1 的数值通常显示两位，小于 1 的数值最多显示六位。

## K 线历史区间（CR-004 / DATA-009）

同次请求近五个自然年的日线，历史不足时按实际区间展示，不替代严格的 252 条 52 周指标。high=max(high)、low=min(low)、close=最后有效 close；distance_high_pct=(close/high-1)*100；position_pct=(close-low)/(high-low)*100，高低相同则 null；仅在 indicators.py 计算。价格最多 8 位小数、百分比 2 位。

复权 K 线逐日按 Adj Close/Close 调整 OHLC；volume 保留原始数量（股票为股），缺失 null、零值保留。周 K 按周一至周日聚合：open 首条、high 最大、low 最小、close 末条，volume 仅在周内全部有效时求和，否则 null；日期为该周首条有效数据日期。末周可能未结束。

CR-004 数据质量处理：已验证 Yahoo 的 MNTN/ONON/IOT 含历史 OHLC 矛盾日线。图表不修造价格，跳过并以 skipped_dates 记录、窗口明确提示；受影响周按可用日线聚合，周成交量置 null，避免不完整总量冒充完整周。若最新日异常导致图表最后日期与榜单不同，则图表仍不可用。原榜单计算不变。


## DATA-018：多尺度箱体 v4（CR-012）
本节为当前唯一口径，覆盖v1–v3中的前半校准/后半验证、两个单程为一轮、中位周期、60天优先及未完成周期超时剔除。用户概念与例子见[BOX_DEFINITIONS.md](BOX_DEFINITIONS.md)。原52周指标不变。

### 窗口、边界与触边
- 最近252条复权日线作背景，分别检查60/90/120/252条窗口；历史不足某长度不生成该窗口，不足60条不评估。
- 每窗全段收盘10%/90%分位数（pandas线性插值）为该窗统一L/U。回顾性识别已发生形态；每天窗口滚动、边界可变，不是过去当时已知的交易信号，也非样本外策略验证。
- 绝对高度=U−L。幅度=(U/L−1)×100%，最低20%（仅1e-9浮点容差）；3–8美元幅度166.67%。位置=(最新收盘−L)/(U−L)×100%，越界不截断。
- 触边阈值B=L+0.2×(U−L)，T=L+0.8×(U−L)。close<=B为下区，close>=T为上区，中间不触发。同一区域停留或中途离开又返回不重置锚点；到另一侧才完成单程。
- 所有单程从全窗口首次触边开始统计，用收盘确定先后；不依据同日high/low假设穿越顺序。保存单程日期、相对全年背景索引、交易日索引差和实际收盘涨跌。
- 内部空间=(T/B−1)×100%，不是扣费净利润；边界幅度是筛选门槛，不拿内部空间替代。

### 三个单程为一轮
- 连续三单程：下→上→下→上或上→下→上→下。四个触边turns依次记录side/time/index。不存在仅下→上→下的一轮。
- 按序每三单程分组，相邻轮仅共享终点，不复用单程；每轮calendar_days=第四次日期−第一次日期，含休市日，不额外+1。trading_days是同两端索引差。
- cycle_days为所有已完成轮次calendar_days的算术平均，保留2位小数；round_count=完成组数；无组则null。资格用未四舍五入平均值判定，<=120自然日为qualified，>120为slow，无轮次unknown。
- round_count>=1为verified，否则unconfirmed。最近一轮单独>120不排除，当前未完成周期>120也不排除，完全按用户要求只用已完成轮次平均值。
- 当前未完成从已消耗的3×round_count个单程后对应的触边开始，首次无轮则用第一个触边；pending_completed_legs为剩余0/1/2个已完成单程，pending_days为该触边至最新行情的自然日差；无触边为null。最近侧为low则awaiting_high，否则awaiting_low。
- efficiency=箱体幅度百分点/cycle_days；无完整轮次null，仅供排序，不是收益率。

### 严格待观察与标签
- 尚无一轮且已完成恰好两个交替单程时，计算第三程进度：最近侧low时(close−B)/(T−B)×100%，最近侧high时(T−close)/(T−B)×100%，裁剪0–100。至少50%才算接近一轮，保存third_leg_progress_pct。不得把单向、孤立山峰/谷底或第三程不足一半标待观察。
- 漂移=（窗口后半收盘均价−前半收盘均价）/(U−L)×100%，绝对值<=50为稳定。occupancy_pct是全窗口收盘落在[L,U]比例，仅作描述；由于同段分位估边会天然接近80%，不再把占比当独立验证证据。
- 检查项：幅度>=20%、至少一轮、完成平均<=120、漂移合格。最新3日连续越界先标broken/breakout，单日越界outside；区间内完成均值>120标slow；四项皆合格match（已验证）；无完整轮但两程+第三程半程、幅度/漂移合格为watch（待观察）；其它rejected（未成箱体），零宽度或短历史insufficient。
- 长期排除对每个窗口生效，保留shape_status/shape_reason，不因形态合格绕过。已验证是价格形态标记，不代表业务专项审核已完成。

### 默认窗口与显示
- 优先选择match中长度最短的窗口；没有match再选watch中最短窗口；两者皆无按检查项通过数最多、同分最短展示不合格原因。所有窗口保留供对照，切换不改表格排序或成员。
- 宽转窄仅默认形态match才标记：较长窗口包含当前L/U，当前绝对高度<=较长高度80%，较长窗口至少两个单程；取符合者最长窗对照。仅多尺度收窄参照，不声称已识别收窄发生日期。
- 排序：match、watch优先，其它原因标签在全部结果查看；同状态按efficiency降序、passed_count降序、position升序、代码。默认仅match/watch，不把未知/失败标签作为候选。
- schema_version=4：cycle_days语义改为算术平均，rounds由三个点改为turns四点，新增window_start/window_end/recognition_method和pending_completed_legs/third_leg_progress_pct；去除formation字段。前端拒绝旧v3，不允许旧两段周期混进新定义。

### 长期背景过滤（保持CR-008）
- 最新日往前四个自然年的可用复权OHLC：long_position_pct=(最新收盘-最低low)/(最高high-最低low)*100，零区间null。原历史首日<=四年截止日+7自然日视为跨度完整；实际日数、起止始终展示，不能将不足四年称完整。
- year_return_pct=(最新收盘/252交易日前收盘-1)*100，需253条，否则null；year_low_gain_pct=(最新收盘/最近252条最低low-1)*100，不足一年标明实际历史。
- 长期位置>=80% OR 一年涨幅>=100% OR 低点反弹>=200%：该股票每个窗口均status=excluded，保留原shape_status/shape_reason及证据。比较窗口不能绕过这一过滤；不自动从活跃名单删除。
- 长期图每5交易日采样加尾点，指标用全部历史。长期图投影当前查看窗口的L/H，不表示历史上一直有该箱体。
- 缺失扫描期日线、版本/代码/日期/复权不符显式报错。日线生成失败不以假数据补齐。


## DATA-016：日线RSI(14)与年内百分位（CR-010）
- 使用对应口径全部可用收盘历史（流水线请求五年），不能每年或每次最近14天重新初始化。复权/未复权分别计算；箱体直接复用同批adjusted行rsi对象。
- 前14个涨跌变化（15个价格）分别取正涨幅与负跌幅绝对值的简单平均作为初值；此后平均涨幅=(前值*13+本日涨幅)/14，平均跌幅同理。RSI=100-100/(1+平均涨幅/平均跌幅)。
- 平均涨跌均0时RSI=50；只有平均跌幅0为100，只有平均涨幅0为0。历史少于15个有效价格则null。遇到非正/非有限收盘重置连续种子，最新无值不沿用旧日冒充当前；沿用行情层有效日线口径，不补假价格。
- RSI保存及显示一位小数，以该显示值<=30为oversold、>=70为overbought、中间neutral；两端有颜色及文字，不单靠颜色。
- 百分位样本为“最新行情日期所在自然年”的每个有效日线RSI，包含当日，平滑历史不在年界截断。使用未四舍五入RSI比较，等值绝对容差1e-10，中位秩百分位=100*(低于当前的数量+0.5*等于当前的数量)/有效样本数量。所有值相等则P50，并非P100。
- 有效RSI样本>=20才输出percentile_ytd（保留一位小数）；否则null且状态insufficient。当前RSI不可用时百分位也null，不拿旧日RSI排名。
- P<=10为low（年内偏低），P>=90为high（年内偏高），其他normal；此分类与RSI超卖/超买独立。样本日期和数量随结果携带，使用行情日年份而非页面打开日年份。
- 这是该股票自身年内动量位置，不是价格位置、跨股票排名、上涨概率或预期收益。仅辅助展示，不进入榜单排序或箱体筛选。


## 两年RSI走势（DATA-017）
先按与榜单RSI相同的完整有效日线计算Wilder14，再截取最新行情日减两个自然年至当日的有效RSI点。不能先裁价格再计算，否则平滑起点会改变结果。最新点与榜单RSI共用一位小数口径。前端仅按日期绘图，不计算RSI、百分位或金融阈值。历史完整性容许7个自然日的休市差；不足明示实际可用范围。
## DATA-024：近3月日均波幅 `volatility_3m`（CR-020）

用于跨股比较历史日常摆动幅度，不是收益率、方向、年化标准差或破产概率。借鉴[ATR真实波幅](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atr)与[ATRP百分比比较](https://www.fidelity.com/learning-center/trading-investing/technical-analysis/technical-indicator-guide/atrp)的思路，但本项目先逐日除前收盘再平均，**不是标准Wilder ATRP**。

以该标的最新有效日线日T为结束，S=T向前移3个自然月（月底按日历回退）；纳入S < trade_date <= T的日线，含最新日。

```text
TR_t = max(high_t-low_t, abs(high_t-close_(t-1)), abs(low_t-close_(t-1)))
日波幅百分比_t = TR_t / close_(t-1) * 100
value = 所有纳入日波幅百分比的算术平均，保留2位小数
```

要求可用历史覆盖S（至少一条S或此前记录作首个前收盘基准），且窗口内至少40个有效日线样本；否则value=null/status=insufficient，不用IPO以来短历史冒充完整三个月。每条high/low/close及前收必须有限且>0，并满足low<=close<=high，否则整项null/status=invalid，不跳过异常日美化结果。按现有有效日线序列相邻点计算，不新增交易所日历；40样本是最低门槛，不保证所有应交易日都齐全，因此提供真实sample_count和窗口日期。

adjusted/raw分别计算且不混用。跨股票比较默认建议复权价；公司行动可能影响不同口径。股票、ETF、指数和加密均按三个自然月，各自交易日数不同，不强行令加密只取63天。

对象字段：value、window_start（排除边界）、window_end（包含）、sample_count、status（available/insufficient/invalid）。旧JSON可缺对象，显示—；零波幅是真实0。主表常驻列，可降序排序（缺失置后、同值按代码），默认和其它指标仍保持原排序。箱体复用同批复权对象，仅详情展示，不改变筛选算法。
