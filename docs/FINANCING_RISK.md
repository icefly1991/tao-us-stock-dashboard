# 融资／稀释风险

CR-039 / UI-039 / DATA-034 / RES-015。2026-10-06用户确认。

## 为什么合并列但保留三行

主表用一列降低横向宽度，标签下固定显示三个维度，避免仅靠颜色或总分丢失信息。第一行已发生稀释，第二行潜在稀释，第三行融资紧迫性；信息块整格可点击，支持键盘及手机，详情保留数字、日期、来源和未知项。文字标签不依赖颜色。三张主表共同使用，原指标排序保持；风险筛选只改变显示范围。

融资完成可增加股数同时改善现金状况。股数增长来自增发、并购换股、股权激励等，不能一律判为资金危机。经营支撑、公司生存风险与此分级独立。亏损、融资需求或高波动本身不否定实质业务；不设置持有禁令，不自动删除名单。

## 三个维度

| 维度 | 核查内容 | 显示与局限 |
| --- | --- | --- |
| 已发生稀释 | 约3/6/9/12个月可比时点普通股数、原因及已完成发行 | 优先12月变化；不是股价下跌，也不等于每股价值同比损失 |
| 潜在稀释 | 公司新股发行、ATM已披露余额、认股权证、预付认股权证、可转债、可转优先股 | 优先关键额度/潜在股数及条件；不能把注册或转售等同已发行 |
| 融资紧迫性 | 可用现金和可动用短期投资、历史消耗、12个月偿债、授信及后续已完成融资 | 优先明确偿债/资金缺口；覆盖月数为历史消耗估算，不是确定生存期 |

入口维护原文核实短语，不自动提取数值或评分。CR-040新增可比股数计算器 `calculate_financing_share_growth`，只在 `scripts/data_pipeline/indicators.py` 计算；人工先核对股份范围、拆并股及两实际日期，再通过actual.comparison输入。生成器重算summary及share_growth_pct，React只展示。股数增长=(最新可比股数/历史股数−1)×100%；正负值均保留。必须采用相同股份范围，先调整拆并股/ADR比例，不能把加权平均股数与期末股数混比。历史观察不必恰好落在自然月日，必须展示两实际日期及实际跨度；缺乏约一年可比点时不假装12月变化。3/6/9/12月观察允许70–115/150–215/240–310/330–400自然日；不能将季度点标成一年。多类别及IPO基准不足需专项复核。

ATM余额/市值=已核实披露余额/研究时点普通股市值×100%。两个日期都记录。市值须普通股总数×未复权价格且股份范围一致，不使用流通市值或复权价格。旧额度未扣已售、不确定终止/替换或证券范围时不计算。此比率表示规模，不是已发生稀释百分比；若新增股数/原股数=x，则原股东持股比例损失为x/(1+x)，不能互换。

潜在股数需保留转换价、到期、行权条件和情景；浮动/重设价格无法确定上限时不伪造固定数值。价外认股权证、未授予计划额度与确定可转换股数分开；已发行股份不再计入潜在股数。同一融资的注册、补充招股书、完成公告和股数增长关联同一事件，不重复叠加评分。

现金覆盖只对适用公司，按同期间且可比的现金消耗计算；融资后现金与旧报告消耗期间分别记录。资金限制、资本开支、偿债与后续变化另列。银行、保险、金融投资结构需专门口径，不能套用公司现金消耗月数。每股收入增长若将来加入，使用可比期间平均股数且列为业务辅助，不进入融资等级。

## 分级依据

不采用文章未经验证的0–100分数。20%股数增长、30%ATM/市值等只作核查线索，不是单独触发最终等级的硬线。

| 等级 | 必须说明的依据 |
| --- | --- |
| 严重 | 原文支持的迫近资金缺口，叠加不利融资条款或融资受阻；逐只说明缺口、时间及后续进展 |
| 高风险 | 明确资金需求叠加大额潜在稀释，或重大已发生稀释且融资依赖持续；逐只解释规模与资金需求 |
| 关注 | 已核实明显股数增长、融资依赖/计划或潜在稀释，但证据不足以证明紧迫危机；可以部分核实，同时明示缺口 |
| 暂未发现突出信号 | 三维关键资料均完成核查且未触发前述条件；不是安全评级 |
| 待核实 | 关键事实不足，不能形成上述判断；无数据不能判低风险 |
| 不适用 | ETF、指数及加密等非公司资产；页面仅显示“—”，无卡片或详情按钮；份额申赎不直接套用公司增发模型 |

高风险/严重可凭充分的已核实关键红旗提示，不要求无关资料全部齐全；未知维度仍未知。解除等级必须有后续原文，不能因资料过期或无新申报自动解除。无标记、低增长、正现金流、ATM余额未知均不等于安全。

## 证据与维护

优先SEC财报、发行文件、8-K/6-K附件及公司IR。仅凭S-3/F-3/S-3ASR/424B5标题或关键词不能判发行发生，须区分公司新发行、老股转售及股票/债券。先核查证券主体、注册生效、宣布、完成、终止状态，境外发行人和私募不能只搜424B5。SEC API只覆盖标准taxonomy及全主体事实，缺公司自定义/维度字段时读原文，不能推断没有。[SEC API](https://www.sec.gov/search-filings/edgar-application-programming-interfaces)、[SEC表格解释](https://www.sec.gov/rules-regulations/staff-guidance/corporation-finance-interpretations/securities-act-forms)。

人工唯一入口 `scripts/financing_assessments.json`；生成 `public/data/financing-review.json`。CSV仍唯一成员来源。维度各有summary、detail、事实日期as_of及sources；未知维度as_of=null、sources=[]，显示待核实。研究日期reviewed_at仅对应本轮逐只融资核查，partial表示部分核实，complete要求三维均有原文且判断明确。输出generated_at只是生成时间，不续期事实/研究日期。维度as_of取对应财报观察点、明确融资事件日或该项已披露时点；无关董事变动/例行申报不得续新旧融资事实日期。过30天提示复核，不自行改级。失败不覆盖旧快照。

纳入 `MONTHLY_REVIEW.md` 同轮人工研究，运行 `python scripts/generate_financing_review.py` 并核查覆盖和缺口。不新增日常/周度自动任务。仅旧估值融资/稀释假设不能转成实际事件；不由每日行情推进静态市值或研究日期。
