# 箱体、一轮和平均周期：用户确认口径

2026-09-19 · CR-012 / DATA-018 / UI-016 · v4已于2026-09-20发布（3e3bdd7）。

用户确认三个交替单程为一轮、上下各20%价格区域算触边、只按已完成轮次平均时间筛选。用户希望保留多个长度、接近肉眼看到的完整形态，因此采用全窗口回顾性识别；60/90/120/252交易日是实现窗口，252约一年，不是周期的自然日单位。精确算法以[METRIC_DEFINITIONS.md](METRIC_DEFINITIONS.md)为准。

## 1. 箱体上下沿与幅度

设下沿为L、上沿为U，要求U>L>0。

- 绝对高度：U−L，单位为美元等价格单位。
- 箱体幅度：**(U/L−1)×100%**，表示从下沿上涨到上沿的理论价格涨幅。
- 箱体3–8美元：高度5美元，幅度**166.67%**；不是5%，也不是8→3跌幅的62.5%。
- 筛选幅度必须**≥20%**，包含恰好20%。它不是实际净利润，不扣费用，也不保证能在两个端点成交。

每个近期窗口使用全段日收盘10%/90%分位数作为一组统一边界，降低少数尖刺影响；不为每次涨跌单独重画。日线图仍显示完整OHLC，算法触边只用收盘价。每天滚动更新窗口和边界，属于对已经发生的形态作回顾描述，不能解释为过去当时就能知道边界的交易信号。

## 2. 触边与一个单程

底部触边阈值B=L+0.2×(U−L)，顶部触边阈值T=L+0.8×(U−L)。

- 收盘≤B视为进入下区，收盘≥T视为进入上区；B<收盘<T为中间区域。
- 同侧停留、离开后未到对侧又返回，都不新增触边，也不重置时间。首次进入相反区域才追加事件、完成一个单程。
- 3–8美元示例：B=4，T=7。收盘先到4或以下、随后到7或以上，算一个上行单程；反向为下行单程。
- 不能用同一天的最高和最低假定日内先后顺序。越界价格仍可形成触边事件，但当前突破、跌破及高位过滤另行决定候选资格。

## 3. 一轮与一轮周期

**一轮必须有四次交替触边、三个连续单程：**

- 下区→上区→下区→上区，例如3→8→3→8。
- 上区→下区→上区→下区，例如8→3→8→3。

3→8或3→8→3均不是完整一轮。一个山峰或谷底也不是完整一轮。

一轮周期=第四次触边日期−第一次触边日期，单位为**自然日**，周末和假期计入；起止日期相减，不额外加一天。文案采用“一轮周期”，避免“一个周”被理解为七天。

按时间先后从第一个触边起计，每三个单程组成一轮。下一轮可共享上一轮终点，不能复用任何已统计单程。9个连续交替单程只算3轮，不能用滑动重叠窗口虚增成7轮。

## 4. 平均四个月内

平均周期=全部已完成轮次的自然日耗时之和÷已完成轮数。采用**算术平均，不是中位数**。

- 平均周期**≤120自然日**达标，作为四个月的统一计算近似，不是120个交易日。
- 仅一轮时均值就是该轮；无完整轮次时平均周期为空，不能猜测或外推。
- 例如30、30、180天三轮：均值80天，仍达标；不能因为最后一轮180天而另行排除。
- 当前未完成轮次从上轮终点（尚无完整轮时从首次触边）算起。**不纳入平均、不因其已超过120天而排除。**始终显示已完成单程数和已耗天数，让用户自行判断近期节奏。

## 5. 标签

| 标签 | 判定 |
|---|---|
| 已验证 | 至少完整一轮；箱体幅度≥20%；已完成轮次平均≤120自然日；价格中枢漂移合格，当前处于箱体内，未触发四年高位过滤 |
| 待观察 | 尚无完整一轮，已完成两个交替单程，第三单程从触边区域向对侧推进至少一半；幅度/漂移/当前价格/长期过滤合格；平均速度未知 |
| 未成箱体 | 幅度不足、漂移过大或往返证据不足，包含单向、孤立山峰/谷底及第三程推进不足 |
| 平均周期过长 | 已完成轮次平均>120天，不是因为未完成周期过长 |
| 向上突破 / 下破箱体 | 最新连续3个交易日收盘高于上沿/低于下沿 |
| 暂时越界 | 最新收盘越界，但未达到连续3日确认 |
| 高位 / 暴涨排除 | 保留既有四年区间及一年暴涨过滤，形态原始标签仍可查看 |
| 历史不足 | 不足60条日线或没有有效价格区间 |

“待观察”的第三程至少一半指价格进入箱体中线或越过中线，朝与最近触边相反的方向。仅3→8→3后没有明显反弹，不能算待观察。此50%是为落实“接近一轮、不是山峰”选用的明确实现门槛，不是用户逐字指定的比例。

已验证只表示历史价格形态合格，不意味着财务/基本面已尽调，也不保证未来重复。

## 6. 多窗口与保留限制

分别扫描60/90/120/252交易日，先选已验证的最短窗口；没有已验证，再选待观察的最短窗口。更长窗口仍在详情可比较，不根据最高历史收益挑选窗口。四年背景、高位过滤、非中概活跃池与手动名单维护保持不变。
