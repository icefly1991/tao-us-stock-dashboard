## 基本面分级

本轮是基于公开财报的风险筛查，不是信用评级、估值结论或买卖建议。亏损本身不等于业务差，现金充足也不等于不会融资。分别显示报告期、盈利、经营现金流、现金、融资和业务证据。

- **经营支撑较好**：可核验经营收入、同期间盈利和经营现金流为正；仍需查看债务、行业和特定风险。
- **亏损/转型观察**：业务可核验，亏损或现金流偏弱，但没有足够证据判为紧迫融资依赖；现金储备与消耗需同时看。
- **融资/经营压力**：负经营现金流、现金覆盖较短并有融资证据，或公告明确持续经营/流动性压力；不把资本开支增长融资自动等同于生存依赖。
- **待核实**：近期可比财报、业务、重组后主体或行业适用指标不足，不强行归为尚可。

研发期生物科技、核能、矿产开发等单列“商业化前期”标签，不因暂未盈利断言业务模糊。加密资产储备、金融、REIT和投资公司须考虑行业会计差异；通用现金消耗公式不适用时不套用。

证据优先SEC XBRL/原始申报及公司IR。每项指标记录单位、起止日期、申报日与来源，禁止将季度利润和全年现金流拼为同期间结论。现金覆盖仅用同币种现金/期间经营净消耗年化估算，标注未计资本支出、偿债及后续融资；非预测。缺失数字不补零，最新财报不能使用核查日之后的申报。

详情默认折叠；等级与风险提示简短展示，可筛选。核查日期独立于每日行情；旧核查不会随行情更新冒充新研究。

## 本轮规则实现与维护

当前234只：40经营支撑较好、125亏损/转型观察、12融资/经营压力、57待核实。23只做原文专项判断，其余为结构化财报初筛。逐只依据见[2026-09-27报告](reviews/2026-09-27-pool-review.md)。

筛查器scripts/research_pool.py选取核查日之前申报的最新经营现金流期间，以相同起止日期/币种匹配收入和利润，现金/流动资产匹配期末。缺失不填0，不跨季度/全年拼接。默认报告期超过200天、金融保险地产投资行业或必要字段缺失归待核实。若盈利、经营现金流、收入均正且未发现流动负债超过流动资产，标为经营支撑较好（仅初筛）。亏损/现金流不佳一般为观察；只有经营净流出、全部流动资产按同期间消耗年化覆盖不足12个月且融资现金净流入，才触发定量压力。人工原文核查可根据已完成融资/特殊行业覆盖初筛，但必须保存日期与来源。

现金覆盖月数 = 现金及等价物 / 经营净消耗 × 报告期自然天数 / 365.25 × 12；这是独立研究辅助值，不属于行情指标，不进入箱体计算。现金和流动资产不是完整可用资金承诺，详情明确其限制。

scripts/pool_review_overrides.json保存23只人工结论；public/data/pool-review.json为版本1静态研究产物，包含逐项数字/单位/期间/申报日/直接来源，日常行情生成不写此文件。更新研究时下载SEC companyfacts/submissions至证据目录，阅读当期原文和期后公告，再运行：

```text
python scripts/research_pool.py --evidence-dir .cache/tradingview/sec --cutoff 2026-09-27 --source-manifest docs/reviews/2026-09-27-pool-sources.json --overrides scripts/pool_review_overrides.json --output public/data/pool-review.json
```

该命令复现本轮，而非自动更新。新一轮应新建来源快照/报告、重新核对成员与中概边界、下载最新财报并同步人工结论日期；脚本拒绝用新日期冒充旧人工研究。成员只改CSV；pool与tier不得同时归属，持仓与pool可重叠。新名单变动时同步研究JSON与安全占位集合，完成真实行情及浏览器验证后发布。SEC地址/注册地仅作线索，中概边界以经营主体等原文核实，不能单看Yahoo国家标签。
