# 高风险公司股票池：经营困境与潜在反转跟踪

2026-09-27用户明确用途：跟踪经营困难、商业化尚未兑现或依靠融资发展的公司，观察未来困境反转。池名不代表所有成员存在财务危机，也不代表已经具备反转价值。原234只成员不变，经营已有支撑的公司保留作为对照。

页面`#/pool`（高风险公司股票池）、`#/pool-boxes`（高风险公司箱体研究）均支持经营类型与基本面等级交叉筛选。选项数量为全池数量，箱体另叠加形态条件；价格公式、默认52周内进度和箱体v4不变。

## 两个独立维度

| 经营类型 | 研究重点 |
| --- | --- |
| 临床研发型 | 医药“彩票”的可核验表达：主要价值依赖临床数据、审批及授权；合作收入不代表核心药物商业化 |
| 商业化前期 | 核心反应堆、飞行器、电池或矿产项目尚待许可、建设、量产、交付；少量研发服务收入不等于核心业务落地，IMSR为代表 |
| 亏损融资型 | 有实际业务但经营未自给，亏损/现金消耗由外部资金支持，GEMI为代表；融资后储备多仍可属于此类型 |
| 经营修复/扩张 | 已有经营活动，但盈利、现金流、需求、资产负债表或扩张兑现仍需观察；亏损不自动等于融资续命 |
| 医药商业化 | 已有获批产品或商业业务，跟踪销量、安全性、报销及盈利。RCKT获批但期内无产品收入，DNLI已销售，均区别于纯临床 |
| 数字资产型 | 持币、挖矿、质押或交易投资；资产重估损益与经营现金流分开 |
| 金融/地产/投资 | 保险、信贷、经纪、REIT或基金；客户资产、法定资本、贷款周转不当作自由现金 |
| 经营已有支撑 | 财报初筛有利润和经营现金流支撑，作为对照，不强行包装成困境公司 |
| 财报/披露风险 | 财报重述或可靠性问题；业务可确认但完整财务状况不能可靠分级 |

每只一个主要类型，资金压力和其它特征以等级/标签补充。临床、未商业化公司可能也依赖融资，优先展示其业务阶段。专项类型必须有原文依据；其余标注“财报规则初筛”，不自动推断临床阶段、无业务或融资依赖。

资金等级保留经营支撑较好、亏损/转型观察、融资/经营压力、待核实四档，不是买卖评级或破产概率。GEMI为亏损融资型及压力档，IMSR为商业化前期及观察档；研发阶段、现金多和融资依赖可以同时成立。

## 证据与口径

优先SEC和公司原始披露，每个数字保留币种、期间、申报日和链接。手工补查更换期间时替换旧事实，不将季度利润配年度现金流；财政期末与结构化标准日期有差异时分别保留来源日期，不据此计算覆盖。客户托管、受限资金不能计作可自由消耗现金，GEMI客户资产及LAES受限现金均单独排除。

原财报初筛：同期收入/利润/经营现金流为正且无明显流动负债缺口列经营支撑；亏损或负现金流列观察；负经营现金流、流动资产年化覆盖不足12个月且融资净流入提示压力。缺失、报告期超过200天、行业不适用只是补查入口。

现金覆盖月数=现金及等价物÷期间经营净消耗×期间自然天数÷365.25×12。未计资本开支、偿债、投资变现、后续融资，不是存活预测；金融、基金、数字资产、披露风险不显示此估算。已完成融资与计划融资、持续经营疑虑与一般融资依赖分开，不能关键词命中就判危机。
