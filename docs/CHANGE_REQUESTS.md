# Change Requests

本文件只记录对已接受需求或 ADR 的修改。新功能先写入 `REQUIREMENTS.md`；修正文案或不改变行为的小问题不必建立 CR。

## 状态

`Draft`、`Proposed`、`Accepted`、`Implemented`、`Rejected`、`Deferred`、`Cancelled`。
