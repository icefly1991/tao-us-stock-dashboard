# 生存与退市风险核查

CR-022 / DATA-026 / UI-025 / RES-009。用户在2026-09-27提供Financial Distress Filter文章，并确认默认保留全部股票、突出风险且可筛选。目标是发现可能威胁公司持续经营、普通股上市资格或股东权益的事实，不是预测破产概率或给出持仓保证。

## 页面与分层

三个行情主表在股票身份处标记；“只看重大风险”可一键切换，筛选不删除名单。两张箱体页仅在单股详情展示。波幅、经营类型、资金等级和生存风险是独立维度。

| 标记 | 触发依据 | 不代表什么 |
| --- | --- | --- |
| 重大风险 | 经原文核查的当前持续经营重大疑虑、普通股退市决定；以后出现实际债务违约、破产申请或困境重组时专项核实加入 | 不代表已破产、已退市或确定会归零 |
| 风险观察 | 融资依赖与经营消耗、上市合规警告、影响核心经营的许可争议、后续融资缓解但仍需跟踪的持续经营事项 | 不将一般融资或经营亏损等同迫近破产 |
| 核查待补 | 来源不可用或缺少分层资料 | 不按零风险处理 |
| 事件初筛未触发 | 当前没有列出符合上述条件的已核实事件，默认不增加表内标签 | 不代表通过完整财务体检，不是绿色安全评级 |

内控缺陷、监管调查、控制人历史和高管刑事指控另列具体事项。只有能够核实生存/上市影响的事件才具有`distress`标记，不从严重程度、公司名字或新闻关键词自动推断。已解决和历史事件不进入当前生存风险；对新融资等缓解措施记录事实，但没有证据时不宣称持续经营疑虑已正式撤销。

## 本轮覆盖及例子

350个标的中344个公司/基金主体取得定期报告初筛，6个ETF/指数/加密标的不套公司模型。78个代码有88条人工复核事件。生存/上市分层为11只重大风险、7只风险观察；326只未触发已列事件，**这326只没有完成逐只偿债能力评级**。

- HUBG：财报重述和延迟、Nasdaq退市决定及拟申诉。不能写成已经退市。
- CRML、GETY、INV、LZM、NMRA、PRME、RZLV、SANA、SMMT、VELO：所列报告披露持续经营重大疑虑，见逐项原始来源。
- CABA：报告披露持续经营疑虑，后续融资已记录，因此列观察，不隐去原始警示。
- GEMI、LCID、SPRY：经营消耗/融资依赖观察，不能凭现金余额估算就断言即将破产。
- ORBS、BETR：上市合规事项；SOC：环境刑事指控与许可争议，尚非定罪。
- SMCI：共同创始人刑事指控与内控事项另列，不直接当作公司生存危机；CVNA控制人1990年旧案与当前公司调查分开。
- IMSR商业化前期、临床研发公司无收入，不单凭业务阶段标为重大风险。MCD等负净资产也不能脱离回购和现金创造能力直接判危。

逐项来源、公告日及有利/不利进展见[核查报告](reviews/2026-09-27-governance.md)及[覆盖清单](reviews/2026-09-27-governance-coverage.json)。研究基准日为2026-09-27，日常行情生成不自动刷新研究日期。部分境外主体最新定期报告较旧，尚未穷尽所有后续6-K及全球司法记录。

## 文章中采用与暂不采用的部分

采用“先查生存和上市红旗，再研究经营质量”的结构。不采用未经回测的0–100分、硬性买卖/剔除规则、HardHoldEligible或破产概率。持续经营疑虑是具体警示，但没有该段落也不是继续经营的保证，参见[PCAOB AS2415](https://pcaobus.org/oversight/standards/auditing-standards/details/AS2415)。破产公司普通股与公司业务能否重组存续是不同问题，参见[SEC破产投资者说明](https://www.sec.gov/files/investor/pubs/bankrupt.htm)。

尚未全量完成的下一层财务核验明确列于详情，不用猜测数据填满：

1. **可动用流动性**：现金+可变现短期投资，排除受限及客户资产；授信须单列承诺金额、提款条件、到期日，不直接等同现金。
2. **12/24个月债务**：核实到期本金、现金利息、已签再融资、可转债条件和契约；总负债不能代替到期债务。普通置换融资、获得豁免不能自动当成违约或困境重组。
3. **现金消耗**：同口径TTM经营现金流及必要资本支出，季节性和一次性营运资金变化另述；经营现金流内已计现金利息时不得重复加利息。现有pool的现金/年化经营消耗估算不等于文章的完整流动性跑道，也不自动触发本分层。
4. **稀释依赖**：区分实际新增股份、股票激励、可转证券、融资额度与实际提款，识别为维持经营所需的持续融资，不将股票拆合误当稀释。
5. **业务与财报可信度**：收入、毛利和现金流恶化组合，审计意见、重述、延迟申报、审计师离任及相关解释；不凭差异或审计师变化就指控造假。

金融机构、交易所客户托管业务、投资基金和数字资产主体不能套同一个工业公司现金消耗阈值。阈值如12/18/24个月只能作为复核线索，须验证期间、融资后事件和业务特点。

## 维护与验证

`scripts/governance_events.json`为事件唯一人工来源，附`distress: major/watch`的每条证据必须与生存、融资、上市、严重财报或核心业务影响有关。生成器在Python中汇总，不在React计算财务评级。未来实际违约/破产须先扩展事件类型并补原文测试，不伪造本轮未发现事件。

```text
python scripts/research_governance.py --coverage docs/reviews/2026-09-27-governance-coverage.json
```

新增或解除事件需复核后续公告、保留历史及更新研究日期/来源。当前没有自动新闻监控或自动基本面复核任务；用户后续发起复核时按以上清单执行。测试覆盖证据缺失、日期、身份/法律状态、已解决事项排除、风险独立分层、默认全列表、过滤与异常降级。
