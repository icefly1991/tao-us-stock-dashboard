2026-10-01，CR-029 Accepted / DATA-030 / UI-029 / RES-013。用户确认将规则写入文档并开始实现，采用此前推荐的“折现到今天的合理价”，将乐观、保守、极端保守三档情景价格与 CR-028 的分析师低／均／高目标价融合。首期历史为计算、校验和页面框架；现已完成344家公司三档条件估值，6项排除。最新全量结果见文末CR-036及逐只报告。

## 两组价格的含义

分析师低／均／高是 Yahoo 收录的不同机构目标价的统计汇总。情景估值是对同一个主体明确设定不同经营、融资及估值假设后计算的每股价值。两者可以相互参照，但不能把机构最高/均值/最低依次改名为乐观/保守/极端保守，也不能按统一打折比例生成情景价格。

## 已接受的三档定义

| 情景 | 假设与用途 |
| --- | --- |
| 乐观 | 有证据支持的业务进展较顺利，增长、利润率或商业化表现较好；核对达到该价值需要哪些条件 |
| 保守 | 增长或商业化低于较好预期、估值倍数较谨慎，计入必要融资及稀释，但业务仍持续经营；作为判断价格是否有折价的主要基准 |
| 极端保守（压力情景） | 重要项目失败、增长明显受挫、融资条件恶化、股权稀释或债务优先清偿等严重但可解释的情景；普通股价值可能接近或等于零，不是保证底价 |

主展示采用按估值日信息计算并折现到该估值日的每股情景价值，`basis=present_value`。月度静态估值并非每日重算的实时合理价；行内显示实际估值日，超过60天退出主表比较；优先采用最新复核结果，详见PRICE_SOURCES.md。未来12个月目标价属于另一时间口径，不能混用。

## 融合展示

三张股票主表只显示乐观／保守／极端保守，汉字档位名称在两行“建议价”表头，行内显示价格、相对未复权现价空间及必要状态；来源仅点击后详情。详情保留机构低／均／高中性参考，明确非建议买入价，不参加建议价颜色或补空白。情景三价按实际复核日≤60天展示；机构参考显示抓取与报告日期，报告未知明确标注，旧抓取标历史快照。现行交互以CR-035和PRICE_SOURCES.md为准。

每只情景必须有模型、估值日、财报基准日、币种、来源、关键假设及股数/稀释处理说明。资料不足显示“情景估值待核实”，不从分析师价格或52周低点补数。月度研究更新情景假设和分析师快照；日常行情只更新价格对照。

## 逐只研究与模型

AI/维护者承担模型选择和原文核查，用户无需逐家公司设计公式。成熟经营公司可用现金流及适用倍数交叉核对；高增长或亏损公司需明确收入、长期利润率及融资路径；临床/商业化前期公司需具体项目、成功概率、现金需求及稀释；金融、地产、数字资产等采用适用资产/行业模型。本轮按用户要求跳过ETF、指数、VIX和加密资产，三档建议价整组留空，不能机械套公司经营估值。

原有 pool-review 的财务初筛不足以直接计算全池情景价格。本轮已另行逐只核实适用的债务、可动用资金、资本开支、股数及后续事件，在valuation_assumptions.json记录344家公司独立模型；预测与披露事实分开，不能将下载完成或财务初筛当作估值完成。

方法来源：[CFA Institute 股权估值流程](https://www.cfainstitute.org/insights/professional-learning/refresher-readings/2026/equity-valuation-applications-and-processes)、[Damodaran 困境估值研究](https://pages.stern.nyu.edu/~adamodar/New_Home_Page/valquestions/distresspaper.htm)。具体三档定义和展示为本项目已接受的实现选择。

## 首期计算模型与输入责任

现支持 `enterprise_dcf`、`equity_dcf` 和 `asset_recovery` 三个明确模型，全部计算在 `scripts/data_pipeline/indicators.py`。详细公式与数值门禁以 [METRIC_DEFINITIONS.md](METRIC_DEFINITIONS.md) 为准。未支持的行业模型保留待研究状态，不能为了覆盖率机械套用 DCF。

- 企业 DCF：输入未来1–10个完整年度的企业自由现金流（已扣资本支出和营运资金投入）、WACC、终值增长、估值日现金及非经营资产、债务及其他优先权益、预计融资后稀释股数。三情景各有独立假设，但同一个标的 DCF 年数一致。每个年度按估值日起未来一年区间处理，不把部分财年当完整年度。
- 压力回收：输入普通股可分配之前的可回收资产、优先债权、处置成本、回收等待年数、折现率、现有普通股数和现有股东对剩余权益的保留比例（0–1，有条款依据，不设默认值）。债权优先于普通股，余值不能为负。现有普通股被注销时保留比例为0，或剩余资产不足清偿时也应为零；不能用重组后新普通股权益冒充老股东价值。现金、资产和成本必须去重。
- 融资核查：已扣在 FCFF 的现金消耗不得重复扣减；未来融资带来的投入与预测必须一致，新增股份计入稀释股数。不能把客户托管资金、受限现金和未提款授信直接作可分配现金。股权、可转债、优先股及期权的权益顺序须专项核实。
- 三档数值必须满足乐观 >= 保守 >= 极端保守，均为非负有限值；计算拒绝异常而不静默重排标签。零是允许的压力结果，不能用缺失值冒充零。

## 月度研究与验收

唯一假设入口是 `scripts/valuation_assumptions.json`；成员及 symbol 仍由 CSV 管理。每个已估值成员必须完整记录三情景 `model/inputs/assumptions/sources`，经营、估值、融资、稀释四组说明必填，压力情景另有失败事件。必须有 `valued_at`、`evidence_date`、USD 币种及逐只总理由，日期不未来化，原文基准不晚于估值日。

维护者可复制 [空白假设模板](templates/valuation-assumptions.template.json) 的单行到假设入口，核实后填完整。模板没有价格或默认预测，空字段会被生成器拒绝；每条来源为 `{"title":"原文名称与日期","url":"https://原文地址"}`。模板的模型只是字段示范，逐只是否适用仍需研究。

执行 `python scripts/generate_valuation_scenarios.py --require-complete` 全量发布输出独立 `public/data/valuation-scenarios.json`；任何校验失败保留旧快照。CSV 全部成员都有 `available/pending/not_applicable` 明确状态。非公司资产按用户要求跳过、三档留空，不是断言该资产没有价值。生成时间独立于逐只估值日，未完成研究的行日期为空。日常行情任务不修改假设或快照。

验收：可复现 DCF/回收模型、稀释和债权优先处理正确；无来源/缺情景/错误 symbol/日期或异常参数拒绝导出；价格为零与待核实区分；三表同列、弹窗来源/参数可读、键盘/手机可打开；估值资料坏掉时行情与独立机构资料继续展示。完成标准与研究覆盖分别报告。

## 资本回收法的适用限制

临床、核能、矿业、资本密集建设和数字资产等公司无法可靠预测完整经营现金流时，可以逐档采用已核实资产及明确的项目出售条件估值。三档须分别解释商业化、出售或停止追加资本的条件；保守档采用资本退出时，明确其与持续经营DCF的差异。资本回收0不表示管线、技术、租约或公司的市场价值已证实为0，亦不得独立作为便宜买入结论。项目受限资金只有与对应债权一起结算的回收情景可以计入，不能作自由现金。完整建设价值和建设现金不得重复；同一子公司权益已扣债后，母公司不能再次扣该债或非控股权益。未来融资必须同时记录费用、可用净额、新股数和融资失败路径。
