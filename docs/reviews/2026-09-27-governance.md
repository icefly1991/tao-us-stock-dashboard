# 重大治理、财报与生存事项核查（2026-09-27）

CR-021 / DATA-025 / UI-024 / RES-008。350个标的中344个公司/基金主体取得定期报告并做文本初筛，6个ETF/指数/加密标的未套公司治理检查。初筛不等于逐份全文尽调或无风险认证；海外发行人部分最近定期报告仍是年报，后续6-K未对全体逐份穷尽。

重点事项原文复核涉及78个代码，共88条记录：当前74条、历史1条、已解决/整改13条。当前事件表示截至所列披露时点未见明确结案/整改证明，不保证核查日之后状态不变。

## 标记原则

- 内控缺陷、重述、监管问询、民事诉讼、刑事起诉和已经认罪/裁判严格区分，不把关键词命中直接发布成事件。
- 不因审计费用、审计师变更、利润现金流差异或做空报告直接认定造假；这些可作后续核查线索。
- 明确涉事人身份与当前关系：共同创始人不自动等于实控人，个人旧案不等于公司现时犯罪。
- 实际退市通知与一般风险因素、权证退市、主动转板不同。没有正式恢复合规证据时，不因股价回到1美元上方便删除通知。
- 持续经营疑虑不等于已经破产；后续融资需要记录，但不自动宣称疑虑撤销。
- 无标记仅表示本轮未列已核实事件。未穷尽全球司法记录、所有关联主体和期后公告，不预测雪崩概率。

## 重点误报排除

- IREN涉及别家公司SEC诉讼的行业背景不标为IREN被调查；APP一般网络安全风险段落不标为公司已受调查。
- APLD/ARM/ATCH/ENVX/GERN/KLAR/KYTX/LZ/ONON/TTAN/UMAC/VITL明确披露历史内控缺陷已整改，保留已解决记录。
- HOOD的2024年Wells通知对应调查已于2025年结束，不冒充当前未结调查。
- FLUT伦敦主动退市、GLXY多伦多退市、SECZ合并转NYSE、SENS转Nasdaq不标普通股被迫退市；PSFE/LUNR权证事项不套到普通股。
- SMCI保留2026年8月公司内部调查的有利结论及三人离职进展；不将内部调查当成刑事案件无罪判决。
