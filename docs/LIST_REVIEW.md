# 活跃股观察列表：质量复核与季度任务

研究日期：2026-09-19。当前名单 99 只（A30/B34/C35），CFLT 已按用户要求移除。本报告是名单结构和代表性公司最新披露的初筛，不是对 99 只逐一完成的尽调或当前价格估值结论；下列升降级/新增建议尚未修改 CSV。

## 判断

这份名单适合作为高波动机会池，但原 A 档不能等同于“跌了可以长期持有”。真实收入、快速增长和高波动，不能代替稳定现金创造、融资独立性和合理买入估值。高质量公司也可能因估值压缩出现多年不修复的回撤。不能把短线亏损自动转为长期持有。

建议分为三组，先满足质量门槛，再比较波动，而不是按最大振幅排名：

1. 核心研究池（目标 20–30 只）：持续现金创造、资产负债表可承受需求下滑、竞争力明确；价格下跌后有条件重新评估持有。
2. 周期/估值观察池：经营有基础，但盈利周期或估值敏感，必须有买入价格和退出条件。
3. 事件/融资观察池：融资、项目兑现、监管或单一产品决定较多，不能默认越跌越加。

## 可复用的筛选规则（研究建议，不是已上线指标）

- 普通非金融企业：看至少八季度收入、毛利率、GAAP 经营利润，TTM 经营现金流减资本支出，剔查预付款、营运资本和一次性现金流。单季正自由现金流不等于稳健。
- 财务韧性：债务到期、利息覆盖、净现金/净债务，以及压力场景下两年内是否必须股权融资；跟踪稀释和股权激励，不能只看非 GAAP 利润。
- 竞争与集中：大客户流失、单一产品、渠道依赖、订单可撤销性、监管变化。
- 估值：用同期股价和企业价值、可持续盈利/现金流做保守/中性/乐观情景，不拿距 52 周高点多远代替便宜程度。周期股看中周期利润。
- 波动与流动性：建议从 60 日美元成交额中位数至少 5000 万、14 日 ATR/收盘价约 3%–7%、60/120 日实现波动率入手；这些只是起始筛选阈值，尚未对全名单计算、未回测。分别报告日收盘涨跌和日内振幅，不能混称“涨跌 10%”。
- 组合相关性：AI 硬件/数据中心、加密/金融科技、广告软件可能共同下跌；公司数量不等于风险分散。
- 持有前写明失效条件：融资缺口、核心客户流失、连续经营恶化、审计问题、投资逻辑不再成立。价格回撤本身不是加仓依据。
