# Requirements

本文件是项目功能范围和验收标准的权威来源。编号前缀：`REQ` 通用、`DATA` 数据、`UI` 界面、`OPS` 部署运维、`NFR` 非功能要求。

## REQ-001：仓库内文档治理

- 状态：Implemented
- 优先级：P0
- 日期：2026-09-14
- 关联决策：ADR-006

### 需求

仓库必须维护 README、长期规则、正式需求、ADR、变更请求、指标定义、运行手册、架构说明和版本记录。聊天或截图不能静默覆盖正式需求。

### 验收标准

- [x] 所有文档存在且职责明确
- [x] 需求、决策、变更和实现可以通过编号追溯
- [x] README 能指导首次运行、修改列表和部署

## DATA-001：使用 yfinance 获取日线

- 状态：Implemented
- 优先级：P0
- 关联决策：ADR-001, ADR-002

### 需求

从 yfinance 批量获取自选标的日线 OHLC。数据层不需要 API Key，前端不得直接请求行情源。

### 验收标准

- [x] Python 可批量下载列表中的 symbol
- [x] 数据至少包含日期、收盘价、最高价和最低价
- [x] 单只标的缺失不会阻断其他成功标的
- [x] 输出声明 `source: yfinance`

## DATA-002：自选列表及特殊代码映射

- 状态：Implemented
- 优先级：P0
- 关联决策：ADR-001

### 需求

CSV 同时保存展示代码、名称、yfinance symbol 和资产类型。首版包含用户三张截图中去重后的 42 个标的，其中 `VIX -> ^VIX`，`DOGEUSD -> DOGE-USD`。

### 验收标准

- [x] CSV 含 `code,name,symbol,asset_type`
- [x] 展示代码唯一
- [x] 支持股票、ETF、指数和加密资产
- [x] 非法类型或重复代码明确报错

## DATA-003：复权价与未复权价

- 状态：Implemented
- 优先级：P0
- 关联决策：ADR-004

### 需求

通过一次 yfinance `auto_adjust=False` 下载获得原始 OHLC 与 `Adj Close`。`raw` 使用原始 OHLC；`adjusted` 使用 `Adj Close / Close` 因子同比例调整 OHLC。两套指标分别计算，不混用历史基准。

### 验收标准

- [x] JSON 在 `adjustments.adjusted` 和 `adjustments.raw` 下输出独立结果
- [x] 前端切换时汇总与表格同步
- [x] UI 使用“复权价”“未复权价”，不沿用 A 股“前复权/除权”文字

## DATA-004：核心趋势指标

- 状态：Implemented
- 优先级：P0
- 关联决策：ADR-003

### 需求

数据层计算当日涨跌、距 MA250、YTD、距 52 周高点、距 52 周低点及 52 周区间位置。公式以 `METRIC_DEFINITIONS.md` 为准。

### 验收标准

- [x] 公式由一个 Python 模块统一实现
- [x] 52 周高低点使用 `high`/`low` 而非收盘价
- [x] 百分比输出为百分比数值并保留两位小数
- [x] 单元测试覆盖完整历史和历史不足两类场景

## DATA-005：历史不足时保留标的

- 状态：Implemented
- 优先级：P0
- 关联决策：ADR-003

### 需求

新上市标的只要有至少两条有效日线，就应显示收盘价和当日涨跌。少于 250 条时 MA250 为 `null`；少于 252 条时三个 52 周指标为 `null`。不得缩短窗口后仍称为 MA250 或 52 周指标。

### 验收标准

- [x] 历史不足不会删除整行
- [x] 缺失长期指标输出 `null`
- [x] 前端显示“—”并把缺失值排在排序末尾
- [x] 输出 `history_days` 便于排障

## DATA-006：时间与错误可追踪

- 状态：Implemented
- 优先级：P1
- 关联决策：ADR-005

### 需求

JSON 分开记录纽约时间生成时间 `updated_at` 和最新常规市场数据日期 `data_date`；周末的加密资产日线不得让美股数据看起来已更新。有错误时输出 `errors`。

### 验收标准

- [x] `updated_at` 包含 UTC 偏移
- [x] `data_date` 与生成时间分开显示
- [x] `data_date` 优先取非加密标的的最新日期
- [x] 全部下载失败时不覆盖已有 JSON，并以失败状态停止部署
