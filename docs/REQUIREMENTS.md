## DATA-003：复权价与未复权价

- 状态：Implemented
- 优先级：P0
- 关联决策：ADR-004

### 需求

通过一次 yfinance `auto_adjust=False` 下载获得原始 `Close/High/Low` 与 `Adj Close`。`raw` 使用原始 `Close/High/Low`；`adjusted` 使用 `Adj Close / Close` 因子同比例调整这三个价格序列。两套指标分别计算，不混用历史基准。

### 验收标准

- [x] JSON 在 `adjustments.adjusted` 和 `adjustments.raw` 下输出独立结果
- [x] 前端切换时汇总与表格同步
- [x] UI 使用“复权价”“未复权价”，不沿用 A 股“前复权/除权”文字
