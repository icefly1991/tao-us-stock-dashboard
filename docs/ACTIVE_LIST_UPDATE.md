# 活跃股观察列表手动更新规范

状态：当前唯一执行流程（RES-005 / CR-008，2026-09-19）。覆盖旧季度自动复核和每周全市场自动发现方案。用户看到超过30天提示后，会主动联系助手更新；不创建定时名单更新任务。日常行情更新和箱体扫描仍只针对现有活跃列表。

## 触发与日期
- 用户明确说“更新活跃列表”时执行此文档；不把打开页面、刷新行情、修改功能当作完成名单复核。
- 成员唯一来源 scripts/stock_list.csv，活跃归属为A/B/C分档；持仓归属保持不变。
- public/data/list-review.json 的 last_updated 是最近一次已完成名单维护日期（北京时间），report 指向对应真实复核报告。若完整复核后无需增删，仍可推进日期，但必须留下“维持名单”的证据。
- UI显示上次更新与北京时间自然日差；大于30天提示可联系助手手动更新，第30天不提示。日期未知/非法/未来值明确提示核实，不伪造0天。
- 本轮仅修改提醒与算法，沿用2026-09-19实际名单维护日期与既有报告，不冒充完成新一轮100家公司尽调。

## 用户偏好与硬约束
1. 高波动、较宽且快速反复穿越的日线箱体、可核验的实质业务；接受CRWV/CRCL型融资、估值和经营风险。不能改成NVDA等波动不匹配的稳健名单。
2. 不选中概，核对实际总部、经营主体、核心业务/VIE/监管；不凭创始人族裔或有中国客户判断。边界从严并留依据。
3. 不要求已盈利或正现金流；核查产品、客户、收入/订单质量、现金消耗、债务到期、融资与稀释、经营和治理变化。缺乏证据标待核实。
4. 排除已核实终止交易的观察成员；普通请求错误不能当停牌或自动删股。
5. 优先约100只，但不能硬凑。手动复核时允许从池外研究替代公司；日常自动形态扫描不扩展全市场，也不自动写入名单。
6. 箱体候选排除长期相对高位与一年暴涨；该价格状态本身不自动删除活跃成员或改变持仓。解释“仍值得观察”和“当前适合箱体研究”的区别。

## 每次执行
1. 读取AGENTS、本文、最新METRIC_DEFINITIONS、CSV和上期复核报告；列出实际成员及持仓交集，不能使用聊天里的过期固定名单。
2. 联网查公司IR/SEC最新财报与重大公告，记录实际查询日期、报告期和直接来源。对收入、订单、现金流、融资与治理重大变化逐一说明；按金融/工业等行业适用指标分析。
3. 用一致复权日线窗口量化波动、美元成交额、箱体宽度、上/下行耗时与次数；记录数据日期和历史不足。按当前指标文档做一年形态和四年高位/一年暴涨过滤，不硬编码某个ticker。
4. 对保留、移除、加入、分档调整分别给出理由与证据。新公司核查非中概、真实业务、ticker、流动性和波动。数据不足不强行下结论，不把有收入或价跌很多等同于可以无限扛跌。
5. 报告保存 docs/reviews/YYYY-MM-DD-active-list.md（同日多次则加后缀），包含逐只结论、来源、增删diff、失败/待核实项、形态与业务两种状态。按照用户已授权范围落实有依据的活跃名单调整，不改持仓。
6. 更新CSV及相应安全占位集合，运行Python/lint/build；验证真实行情成功/失败、data_date、箱体过滤、导航、K线和手机布局。未知或数据获取失败不能记为成功。
7. 完成名单复核与验证后，更新list-review.json日期和report。仅完成部分核查、任务失败、纯UI改动不得更新日期。名单日期不得由每日generate_dashboard或generate_boxes自动写入。
8. 更新CHANGELOG/OPERATIONS及必要需求文档；报告实际生效范围（本地/线上）、成功/失败数量、未解决项和下一步。

## 当前箱体规则（CR-012 / DATA-018）
最近一年背景中扫描60/90/120/252交易日窗口，全段分位边界和穿越计数，回顾性识别已发生形态；优先已验证最短窗口，其次严格待观察。不是前半形成/后半验证的事前信号。可记录宽转窄，箱体幅度至少20%。
一轮为三个交替单程（低→高→低→高或相反），相邻轮不复用单程，上下20%区域收盘触边。已完成轮次算术平均<=120自然日达标，不以未完成或最新单轮超时另行剔除。至少一完整轮为已验证；尚无完整轮、两个单程后第三程推进至少一半为待观察，其它不列默认候选。
四年/可用历史位置>=80%、一年涨幅>=100%或较一年低点上涨>=200%任一满足排除箱体候选。详情和可调整实现规则以METRIC_DEFINITIONS为准；原活跃成员保留供研究。不得暗调门槛凑结果。

“按 docs/ACTIVE_LIST_UPDATE.md 更新活跃股观察列表，保留持仓归属，完成后更新名单日期并给我变更报告。”


### 公司业务短标签
维护成员时同步核对 scripts/stock_list.csv 的 business 字段，使用简短的实际业务词组，避免只写“AI”等含糊概念。更名、转型公司需查官网/公告，不把标签当作基本面可靠性的评级。ETF、指数及加密资产描述其资产或策略；不修改本轮名单日期来标记普通UI调整。
