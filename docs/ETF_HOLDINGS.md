# 行业／主题ETF持仓核查（CR-049 / DATA-038 / UI-045）

页面只显示有发行商官方直接持仓证据的行业或主题ETF。覆盖持仓与活跃联合公司；ETF、指数、加密资产不套用公司所属基金，隐藏池非重合成员暂不扩研究。一个公司可以同时由多个ETF持有，所选代码不是唯一归属。

## 证据与选择

1. 下载发行商完整基金持仓或读取其官方完整持仓表，确认是基金实际持仓，不是指数成分或交易所创建篮子。
2. 使用CSV查询symbol匹配，另核对公司名称、股票类别及CUSIP/SEDOL等身份标识；部分iShares CSV只给代码和交易所时明确以其为标识，不编造CUSIP。PSTG展示别名必须匹配查询代码P。不同类别、权证、互换、期权与间接基金敞口不能替代该股直接持仓。
3. 必须有正股票数量与正权重，记录发行商持仓截至日、核查日、来源URL和下载原文SHA-256。核查当日拒绝超过30天的资料；HTTP失败、日期不明、旧快照均不能作为新证据。
4. 在真实持仓的候选中优先匹配业务主题；大行业基金确实持有时可保留，细分行业基金及主动主题基金也可选。KOMP明确是多行业创新经济主题，不把它描述为单一行业；不以VTI、IWM等宽基或单股杠杆基金凑数。
5. 未找到可用证据时移除旧推定代码，显示“未找到已核实ETF”。这只表示本轮来源核查未找到，不代表全市场没有任何ETF持有该公司。

## 唯一维护入口与发布门禁

`scripts/stock_list.csv.sector_etf`唯一维护页面所选基金；`public/data/sector-etf-review.json` v1保存129家公司核查状态、所选基金的官方持仓事实及基金来源目录。证据重复记录代码仅用于核对CSV，不构成另一个名单维护入口。逐只原始持仓行摘录、原文哈希及无证据记录见本轮[证据存档](reviews/2026-11-06-etf-holdings-evidence.json)。原始完整下载仅保存在本地缓存，不提交巨量网页或临时Cookie。

`scripts/data_pipeline/sector_etf.py`校验官方HTTPS主机、公司symbol、基金、直接股权类别、数量/权重、日期、基金目录及研究范围；CSV和证据错配使生成失败，不带着旧标签发布。运行`python scripts/validate_sector_etfs.py`可只核对研究数据。

每日行情只透传已研究证据，不抓取ETF持仓、不推进核查日期。dashboard行/停牌摘要兼容增加可选`sector_etf_holding`；boxes v4行同样增加该对象及可选`symbol`，以支持展示代码别名核对。旧快照仍可读，但仅有旧`sector_etf`字段不会被显示为持仓已核实。

## 页面与维护

ETF代码链接到官方持仓来源，下面显示持仓截至月日，完整日期、公司、股数、权重与核查日在提示信息中。超过持仓截至日30天显示“待复核”，保留明确的历史日期和原来源，不冒充当前持仓。仅代表该日官方快照，ETF之后可能买卖，不能保证实时或未来持续持有。

月度或用户手动发起时重新核查所选基金完整持仓与新增公司，保存新证据并同步CSV；不只改日期。若原基金已卖出，查其它合适行业/主题ETF，找不到则留空。ETF核查不推进其它人工研究或名单维护日期，不注册自动任务。验收包括两口径、停牌、旧快照、来源失败/不匹配、过期、手机/桌面与箱体详情。
